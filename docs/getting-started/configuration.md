# Configuration

The main configuration is the managed `--ram-budget`, accepted as raw bytes or binary K/KB/M/MB/G/GB. `--cache-size` is exposed by the server but cache admission is not yet integrated into the serving engine (**planned**). `--vram-budget` is not implemented. `--api-key`, `--no-auth`, `--request-timeout`, `--host`, and `--port` configure the local server.
