# Configuration Reference

| Option | Status | Meaning |
|---|---|---|
| `--ram-budget` | Implemented | Managed runtime memory ceiling |
| `--cache-size` | Experimental | Accepted server option; cache population planned |
| `--vram-budget` | Not implemented | Future GPU budget |
| `--api-key` | Implemented | Local Bearer key |
| `--no-auth` | Implemented | Disable local auth explicitly |
| `--request-timeout` | Implemented | Server request timeout seconds |
