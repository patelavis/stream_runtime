# Security Policy

This project is designed for local/offline use and binds to `127.0.0.1` by default. Do not expose it to a network without understanding authentication and deployment risks. Never commit model credentials or API keys.

For a suspected vulnerability, do not disclose exploit details in a public issue. Contact the maintainers privately with affected version, reproduction steps, impact, and suggested mitigation. This repository currently has no automated telemetry or external reporting service.
